GRC USTASI · BİR DEFALIK IPHONE KURULUMU

{{ shortcut_name }}

Bu adımlar Alarmları Bul eylemi bulunan iOS 17 ve üzeri içindir. Kurulum Saat uygulamasında gerçek alarm oluşturur. Sonraki günlerde Telegram düğmesi → “iPhone’da alarmları eşitle” → Kestirmeler açılışı yeterlidir. iOS ilk kullanımda izin veya çalıştırma onayı isteyebilir. Henüz iPhone’unda kurulup denenmedi; ilk çalışmada aşağıdaki kısa testi yap.

1. Boş kestirmeyi oluştur

iPhone’da Kestirmeler → + → Yeni Kestirme aç. Adını harfi harfine {{ shortcut_name }} yap. Otomasyon oluşturman gerekmez. Eylem adları telefon diline göre Türkçe veya İngilizce görünebilir.

Aşağıdaki blokları sırayla ekle. Bir değişkeni seçmek için eylemdeki giriş alanına basılı tutup Değişken Seç / Select Variable kullan.

2. Telegram’dan gelen güncel listeyi oku

  1. Eğer / If: Kestirme Girdisi {{ input_prefix }} ile başlamıyorsa Uyarı Göster (“Yalnız GRC Ustası bağlantısını kullan”) ve Bu Kestirmeyi Durdur. Bu Eğer bloğunu bitir.
  2. URL’nin İçeriğini Al / Get Contents of URL: URL alanı Kestirme Girdisi / Shortcut Input, yöntem GET.
  3. Değişken Ayarla / Set Variable: çıkan sözlüğü Veri adıyla sakla.
  4. Sözlük Değerini Al / Get Dictionary Value: Veri içindeki version. Ardından Eğer / If: sonuç 1 değilse Uyarı Göster (“Bugünkü Telegram mesajını kullan”) ve Bu Kestirmeyi Durdur / Stop This Shortcut. Eğer bloğunu bitir. Böylece bağlantı hatasında mevcut alarmlar değiştirilmez.
  5. Sözlük Değerini Al: Veri içindeki alarms. Sonucu Değişken Ayarla ile Gorusmeler adıyla sakla.

3. Yalnızca eski GRC görüşme alarmlarını kapat

  1. Alarmları Bul / Find Alarms: filtre Etiket / Label ile başlar / begins with {{ prefix }}. Bu filtre yalnızca bu kestirmenin alarmlarını seçer.
  2. Her Biriyle Yinele / Repeat with Each: bulunan alarmlar. İçine Alarmı Aç/Kapat / Toggle Alarm ekle: işlem Kapat / Turn Off, alarm Yineleme Öğesi / Repeat Item. İşlemin “Değiştir / Toggle” değil “Kapat” olduğundan emin ol. Yineleme bloğunu bitir.

Bu adım iptal edilmiş, saati değişmiş veya günü geçmiş GRC alarmlarını kapatır; silme yapmaz.

4. Güncel görüşmeleri eşitle

Her Biriyle Yinele / Repeat with Each ekle; giriş olarak Gorusmeler değişkenini seç. Aşağıdaki adımlar bu döngünün içinde olacak.

  1. Mevcut Yineleme Öğesini Değişken Ayarla ile Gorusme yap. İç döngülerde hangi görüşmede olduğunu kaybetmemek için bu değişkeni kullan.
  2. Sözlük Değerini Al: Gorusme içindeki alarm_at. Ardından Girdiden Tarihleri Al / Get Dates from Input, sonra Listeden Öğeyi Al / Get Item from List → İlk Öğe / First Item. Sonucu AlarmZamani değişkeni yap.
  3. Şu Anki Tarih / Current Date ekle. Eğer / If: AlarmZamani şu anki tarihten sonra / is after Current Date. Sonraki adımları bu Eğer bloğunun içine ekle. Böylece geçmiş saat için yanlışlıkla yarına alarm kurulmaz.
  1. Tarihi Biçimlendir / Format Date: tarih AlarmZamani, özel biçim yyyy-MM-dd HH:mm, saat dilimi iPhone’un geçerli/yerel saat dilimi. Sonucu YerelSaat yap. Sunucunun tarihindeki saat dilimi farkı bu aşamada yerel saate dönüşür.
  2. Sözlük Değerini Al: Gorusme içindeki label. Sonucu TemelEtiket yap.
  3. Metin / Text: değişkenleri seçerek [TemelEtiket] · [YerelSaat] oluştur. Köşeli parantezleri düz metin yazma; iki değişkeni yerleştir. Sonucu AlarmEtiketi değişkeni yap.
  4. Alarmları Bul / Find Alarms: filtre Etiket / Label eşittir / is AlarmEtiketi. Sonucu BulunanAlarmlar değişkeni yap. Ardından Say / Count: BulunanAlarmlar.
  5. Eğer / If: sayı 0 ise Alarm Oluştur / Create Alarm / Add Alarm: saat AlarmZamani, etiket/ad AlarmEtiketi, Yinele / Repeat: hiçbir zaman / none.
  6. Değilse / Otherwise: BulunanAlarmlar üzerinde Her Biriyle Yinele ekle. İçine Alarmı Aç/Kapat → Aç / Turn On, alarm bu iç döngünün Yineleme Öğesi. Böylece aynı alarm yeniden oluşturulmaz; mevcut alarm açılır.

İç döngüyü, “sayı 0” Eğer bloğunu, “gelecekteki tarih” Eğer bloğunu ve görüşme döngüsünü sırayla kapat.

En sona Sonucu Göster / Show Result ekle: “GRC görüşme alarmları eşitlendi. Saat uygulamasından kontrol edebilirsiniz.”

5. İlk çalışmayı doğrula

  1. Bugünkü Telegram mesajındaki ⏰ Tüm görüşmelere alarm kur düğmesine bas.
  2. Açılan sayfada iPhone’da alarmları eşitle seç. Telegram içinden açılmazsa sayfayı Safari’de aç.
  3. iOS sorarsa Kestirmeler’in bu siteye ve Saat alarmlarına erişimine izin ver. iOS’un izin ekranını telefonunda sen onaylamalısın.
  4. Saat → Alarmlar’da her görüşmenin 5 dakika öncesine kurulduğunu kontrol et. Görüşme programı değişmemişken aynı düğmeye yeniden bas; alarm sayısı artmamalı.
  5. Yakın zamanda bir test alarmıyla sesin beklediğin gibi çaldığını doğrula. Telefonundaki ses ve alarm ayarları geçerlidir.

Kestirme GRC alarmlarını silmez. Önceki günlerden kalanlar kapalı kalır; istersen Saat uygulamasından silebilirsin. Görüşme iptal edilir veya saati değişirse güncellemek için düğmeyi yeniden çalıştır.
