# CISM yönetici simülasyonu
100 özgün Türkçe vaka. Resmi sınav soruları kullanılmadı.
Türler mevcut CISA paketinin dağılımıyla aynıdır: choice 20, scenario 20,
sentence_order 20, drag_select 20, multi_select 10, fill_blank 10.
Dört alan dengeli eğitim amacıyla 25'er vaka içerir; sınav ağırlıkları iddiası yoktur.
